# List Menu — Member & Finance Club Bola (TFS / TFDEV)

Struktur menu pengelolaan academy/club: keanggotaan + keuangan operasional.

## 1. Dashboard Club
- Total member aktif / trial / nonaktif
- Tagihan jatuh tempo
- Penerimaan bulan berjalan vs target
- Outstanding (piutang)

## 2. Member
### 2.1 Daftar Member
- Filter aktif, trial, cuti, alumni, tunggakan
- Profil: nama, grup usia, posisi, ortu, status bayar
### 2.2 Tambah / Edit Member
- Data anak + ortu/wali + paket + tanggal mulai
- Catatan medis/alergi + status aktif/trial/cuti
### 2.3 Grup & Tim
- Master U-age, assign roster, kuota grup
### 2.4 Kehadiran
- Absensi sesi, riwayat, alert absen
### 2.5 Trial & Recruit
- Pipeline trial → convert + follow-up ortu
### 2.6 Dokumen
- Form daftar, izin ortu, kartu/QR (opsional)

## 3. Finance
### 3.1 Dashboard Finance
- Kas masuk/keluar, breakdown iuran/event/sponsor, piutang
### 3.2 Paket & Harga
- Trial/Monthly/Term/Season/Private + diskon sibling
### 3.3 Tagihan
- Auto siklus + manual; status draft→lunas/overdue; kirim WA/email
### 3.4 Pembayaran
- Transfer/cash/QRIS; bukti; kwitansi; cicil
### 3.5 Piutang & Koleksi
- Aging; reminder; kebijakan tunggakan
### 3.6 Pengeluaran
- Sewa lapangan, fee coach, alat, marketing; approval; nota
### 3.7 Fee Coach
- Rekap sesi → fee → bayar
### 3.8 Event & Match Day
- Iuran event, sponsor, L/R event
### 3.9 Merchandise
- Stok & jual jersey/alat
### 3.10 Laporan
- P&L sederhana, cash flow, export Excel/PDF
### 3.11 Rekening & Kas
- Multi rekening, saldo, mutasi

## 4. Pendukung
- Staff & Role (owner/finance/admin/coach)
- Notifikasi WA/email tagihan
- Pengaturan club (rekening, template pesan, refund/cuti)

## 5. Prioritas bangun
| Fase | Menu |
|------|------|
| MVP | Member list/add, Paket, Tagihan, Pembayaran, Dashboard finance |
| Fase 2 | Kehadiran, Piutang, Pengeluaran, Laporan |
| Fase 3 | Trial, Fee coach, Event finance, Merchandise |

## 6. Nav sketsa
Dashboard > Member (list/add/grup/hadir/trial/dokumen) > Finance (dashboard/paket/tagihan/bayar/piutang/expense/fee/event/merch/laporan/kas) > Analitik (AI video/Match Centre/Parent/Player) > Pengaturan
