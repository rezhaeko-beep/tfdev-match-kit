Tim Analis · Video → AI → JSON

Analitik AI

Upload video match, ambil frame, siapkan paket untuk ChatGPT/Claude/Grok (atau Vision API), tempel JSON hasil → Match Centre & Parent Report.

Aturan analitik (video-first)

  • Primary evidence = VIDEO / frames — jangan mengarang gol, shot, kartu, atau skor yang tidak terbaca dari footage.
  • N/C & null — angka yang tidak yakin dari wide cam = null + reason, bukan 0 palsu.
  • estimated:true — possession & attacking sequences boleh estimasi; selalu tandai.
  • Alur — Video → frame/prompt → AI eksternal atau Vision API → paste JSON → terapkan.
